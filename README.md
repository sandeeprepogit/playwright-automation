# 🎭 Playwright Automation Framework

A modern end-to-end automation framework built using **Playwright with JavaScript**, designed for **Web UI** and **API testing** with scalable architecture and CI/CD integration.

---

## 🚀 Tech Stack

- 🎭 Playwright (JavaScript)
- 🌐 Web Automation Testing
- 🔗 API Testing
- 🥒 Cucumber (BDD Framework)
- 🤖 AI Agents & MCP Integration
- 🔄 CI/CD Pipelines
- 🗂️ Git Integration

---

## 📌 Features

- ✅ Cross-browser testing (Chromium, Firefox, WebKit)
- ✅ End-to-end UI automation
- ✅ API automation using Playwright
- ✅ BDD support using Cucumber
- ✅ Scalable and maintainable framework design
- ✅ Integration with CI/CD tools (GitHub Actions, Jenkins)
- ✅ Smart automation using AI Agents
- ✅ Modular and reusable components

## ⚙️ Setup & Installation

```bash
# Clone the repo
git clone https://github.com/sandeeprepogit/playwright-automation.git

# Navigate to project
cd playwright-automation

# Install dependencies
npm install

# Install Playwright browsers

# Run all tests
npx playwright test

# Run specific test
npx playwright test tests/example.spec.js

# Run with UI mode
npx playwright test --ui

# Run Cucumber tests
npm run cucumber
npx playwright install
